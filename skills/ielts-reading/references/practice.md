# Reading sessions

## Preferences and sources

Read the private profile first. Use the current request to resolve conflicting earlier instructions; record material preference changes without treating an assistant's old suggestion as a user decision. English-only print content, no printed timings, and separate-page answers are supported preferences, not an assumed learner profile. Include a non-revealing hints section when requested or saved as a preference; omission from a later prompt alone does not prove an earlier preference was revoked.

Prefer suitable official samples from IELTS, British Council, IDP or Cambridge and verify the actual source and answer key online when sourcing new material. Assess individual sources rather than generalizing from one failed source. Retain original instructions, question numbering, choices, word limits and required diagrams. Label official samples, published practice and verified past papers accurately. Record publisher, URL, accessed date, passage reference, key source and relevant reuse evidence. A shared collection URL is not a passage identity.

If the current request or saved preference allows original IELTS-style practice as a fallback, label it clearly as original and explain the fallback. Never substitute it when authentic-only material is required. If sufficient usable material cannot be found, report the precise shortfall; do not create fake source attribution. Do not silently substitute summaries when original wording was requested.

For original passages, vary science, geography, cities, history, society and other topics without overfitting to programming. Keep invented case studies explicitly fictional. Verify factual claims where needed. Choose length and difficulty for the available session capacity without equating technical knowledge with English proficiency. Authentic passages retain their natural length and question set.

## Question and answer checks

- Check every answer against the passage, using no outside knowledge to decide it. Re-solve independently of the draft key. Each question needs one unambiguous supported answer.
- For False/No, explain the contradiction; for Not Given, identify what is missing. Distinguish factual statements from writer claims.
- Check word limits, grammar, exact copied words and whether options may repeat. Ensure matching tasks and diagrams retain every necessary element.
- Give brief plain-English explanations and passage locations. For published material, distinguish the verified published key from editorial explanations. Preserve unresolved source-key discrepancies explicitly.
- Hints must not reveal answers, decisive copied fill-in words, correct options or classifications. Keep initial performance separate from post-hint corrections.

## Print and retain

Use an available PDF skill or suitable renderer and inspect every page. For a pack of independent sessions, create one self-contained PDF per passage plus editable sources. The usual layout is A4 portrait, single column, black text on white, 11–12 pt body, readable spacing and answer space. Avoid covers, decorative filler, split questions, clipped content and orphaned headings; embed suitable fonts and include session/page numbers and source attribution.

Put all answers on a new page after the passage and questions within the same PDF. When hints are included, start them on their own page before a separate answer page. Do not split hints or answers into separate files unless specifically requested. Do not print schedules, countdowns or time estimates when the profile forbids them.

Use cumulative IDs and versioned batch directories, for example `artifacts/batch-02-v1/evening-reading-12.pdf`. Archive actual artifacts and editable content; store relative archive paths in material events. Store delivery/QA notes as separate events so a later rendering fix does not overwrite the original material record. When providing downloads through an artifact workspace, keep an additional durable private copy independent of that temporary workspace.
