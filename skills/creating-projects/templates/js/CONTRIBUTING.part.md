This project is built with [Vite+](https://viteplus.dev/), the unified toolchain for JavaScript. Please follow its [guide](https://viteplus.dev/guide/) to install the global `vp` command, then install dependencies by running:

```bash
vp install
```

To make sure your code can be passed by CI, you can preview the result by running:

```bash
vp run check
vp run build
vp run test
```
